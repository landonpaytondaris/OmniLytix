# OmniLytix Build Sessions

This folder records the beginning and ending notes for OmniLytix build sessions.

Purpose:
- Capture where the build starts.
- Capture what was changed.
- Record files touched, commands used, commits, blockers, and next actions.
- Prevent wasted time trying to rediscover where the project left off.

Session rhythm:
1. Create or update a Start Session Note.
2. Build only the planned slice.
3. Test the UI.
4. Commit and push.
5. Complete the End Session Note.
6. Update the current-state file if the project state changed.
